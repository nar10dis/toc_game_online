Regles :
- Le 7 se joue en plusieurs morceaux, UN emit par morceau (pion, nb de pas, move/enter).
- Il faut utiliser les 7 pas en entier. On ne propose jamais un morceau qui mene a un blocage.
- Rentrer a la maison n'est pas automatique : le joueur choisit (enter: true/false).
- Le 7 capture TOUS les pions sur son passage, les siens compris,

------------------------------------------------
[x] simulateSplitStep(pawns, pawn, steps, enter) -> ActionResult | null (null = interdit)
    - enter :
        1. verifier canGoHomeBy(pawns, pawn, steps)
        2. toEntry = mod(getStartHome(seat) - pawn.position.cell, BOARD_CELLS_COUNT)
           (nb de cases du plateau avant l'entree)
        3. captureAlongPath(pawns, pawn.position.cell, toEntry)
           (capture tout jusqu'a la case d'entree incluse)
        4. poser le pion a la maison sur la case homeCellIndex(seat, from, steps)
    - sinon :
        verifier canMoveBy / canMoveInHomeBy, puis captureAlongPath(pawns, from, steps)
        et poser le pion. A la maison on ne capture rien (canMoveInHome interdit
        deja de depasser un pion).
    - si toEntry === 0, pathCells renvoie [] : rien a capturer, ca marche tout seul.
    - le pion qui bouge ne se capture pas lui-meme (le chemin part de from + 1).

[x] canFinishSplit(pawns, seat, left) -> boolean   (RECURSIVE)
    - left === 0 -> true
    - pour chaque pion a moi, pour n de 1 a left, pour move puis enter :
        after = simulateSplitStep(...)
        si after !== null et canFinishSplit(after.pawns, seat, left - n) -> true
    - sinon -> false
    (au max 7 niveaux de profondeur, on s'arrete au premier chemin qui marche)

[x] getSplitSteps(pawns, seat, cardId, left) -> GameAction[]
