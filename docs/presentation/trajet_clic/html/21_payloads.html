Les messages, tels quels

Les trois messages échangés pour notre coup. Les cartes sont écrites en id.
→ FRONT VERS SERVEUR · « action »
{ gameId: 42, action: { type: "move", cardId: "heart_5", pawnId: 1 } }
← RÉPONSE (ack)
{ ok: true } // ou, si refusé : { error: "Not your turn" }
← SERVEUR VERS CHAQUE HUMAIN · « state » (vue du siège 0, abrégée)
{ state: { // GameView : la vérité à afficher id: 42, phase: "playing", currentSeat: 1, mySeat: 0, myHand: [ "heart_7", "spade_2", "diamond_13", "club_9" ], players: [ { seat: 0, pseudo: "Moi", handCount: 4 }, … ], pawns: [ …, { id: 1, playerSeat: 0, position: { zone: "board", cell: 15 } }, … ], discardPile: [ …, "heart_5" ], drawPileCount: 32 }, event: { // GameEvent : quoi animer seat: 0, action: { type: "move", cardId: "heart_5", pawnId: 1 }, captured: [], newRound: false } }
Les types sont dans game.types.ts et copiés dans gameTypes.ts côté front.
